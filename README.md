# 企業級專案整合入口平台 (Enterprise Project Hub)

一個簡潔、高效且現代化的企業級專案儀表板。自動串接 GitHub API 動態載入個人或團隊專案，並提供流暢的卡牌拖曳排序與即時搜尋功能。

![Platform Preview](https://img.shields.io/badge/Status-Active-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ 功能亮點 (Features)

- 🚀 **GitHub API 自動串接**：自動抓取並動態渲染公開專案列表（包含名稱、語言標籤、描述與連結）。
- 🎨 **現代化 Glassmorphism 視覺**：採用深色模式（Dark Mode）與玻璃擬物化風格設計，視覺體驗佳。
- 🔀 **互動式拖曳排序**：整合 SortableJS，支援卡牌自由拖曳與網格自動對齊。
- 🔍 **即時關鍵字搜尋**：輸入關鍵字即可秒級過濾專案名稱與描述。
- 📱 **響應式網格佈局 (Responsive Grid)**：完美適應 Desktop、Tablet 及 Mobile 各種螢幕尺寸。

---

## 🛠️ 技術棧 (Tech Stack)

- **前端核心**：HTML5, CSS3, ES6+ JavaScript
- **套件與 API**：
  - [GitHub REST API](https://docs.github.com/en/rest) - 專案資料來源
  - [SortableJS](https://sortablejs.github.io/Sortable/) - 卡牌拖曳動畫與互動
